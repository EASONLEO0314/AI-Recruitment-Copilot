# BOSS 新版简历语义解析设计

日期：2026-08-06

## 背景

插件已经能够稳定识别 BOSS 候选人简历所在的独立 frame。现场诊断显示，当前页面使用 `lib-standard-resume`、`resume-detail-wrap`、`resume-simple-box` 和 `resume-item-detail` 等新版结构，而现有解析器仍以旧版 `resume-section`、`history-item` 等类名为主，因此会得到空的工作、教育和项目数组。

本轮不继续猜测公司、职位、日期等细分字段。验收目标是：准确识别工作、教育、项目的条目数量，并完整保留每条经历的可见原文，为后续 LLM 结构化提供可靠输入。

## 方案选择

采用“语义章节解析 + 统一原文字段”方案：

- 使用稳定的简历根节点和通用章节、条目容器定位内容。
- 根据章节标题及明确的章节类名判断工作、教育或项目类型。
- 为三类经历统一增加可选字段 `raw_text`，保存条目内规范化后的完整可见文本。
- 现有的公司、职位、学校、时间等结构化字段保持可选；没有可靠证据时不填充。

未采用以下方案：

- 不把完整原文塞入 `company`、`school` 或 `description` 等语义不一致的字段，避免污染后续分析。
- 不只返回数量，因为这会丢失 LLM 后续需要的经历内容。
- 不读取 BOSS 内部接口或运行时状态，避免增加反爬和账号风险。

## 数据契约

在扩展的三类经历接口中增加：

```ts
raw_text?: string;
```

适用类型：

- `WorkExperience`
- `EducationExperience`
- `ProjectExperience`

`raw_text` 仅保存当前可见条目的规范化文本，不包含 HTML、链接、元素属性或隐藏内容。单条上限为 2,000 个字符；超过上限时截断并附加 `resume-item-raw-text-truncated` 警告，防止异常页面产生过大消息。校验器和快照清洗器必须同步支持该字段；未知字段仍然拒绝。

## 解析流程

1. 在已确认的候选人简历根节点内查找可见的 `.resume-simple-box`。
2. 只在当前章节内部读取标题，不跨章节查找。
3. 按以下顺序判断章节类型：
   - 明确类名，例如 `education`；
   - 可见标题的精确语义，例如“工作经历”“工作经验”“教育经历”“教育背景”“项目经历”“项目经验”。
4. 在已分类章节内查找可见的 `.resume-item-detail`，并保证每个条目只属于最近的章节。
5. 将条目的可见文本规范化为空白分隔的单一字符串，保存到对应对象的 `raw_text`。
6. 如条目同时具有现有解析器已认识的稳定字段，继续保留这些字段；不得通过文本位置猜测公司、职位、学校或日期。
7. 无法分类的章节不进入任何经历数组，并返回受控警告，不制造错误数据。

## 安全边界

解析器继续遵守被动读取原则：

- 不点击、不聚焦、不滚动页面；
- 不发起 BOSS 网络请求；
- 不调用 `chrome.debugger`；
- 不读取 Cookie、localStorage 或 sessionStorage；
- 不读取整个 `document.body` 作为兜底；
- 不记录候选人正文到控制台或诊断信息；
- 忽略 `hidden`、`aria-hidden` 和不可见祖先中的内容。

## 界面行为

“页面读取”卡片继续显示工作、教育、项目条目数量。完整 `raw_text` 保留在本地解析快照中，不直接展开到悬浮窗，避免界面拥挤和不必要的个人信息展示。

当至少识别到一类经历时，页面读取状态可进入 `partial` 或 `ready`，不再显示“候选人结构未匹配”。演示评分仍明确标注为演示数据，本轮不把页面原文接入 LLM 评分。

## 测试设计

先编写失败测试，再实现解析逻辑。测试覆盖：

- 使用现场类名的新版工作、教育和项目章节；
- 每个可见 `.resume-item-detail` 只生成一条记录；
- `raw_text` 保留完整规范化文本，条目数量准确；
- 隐藏章节和隐藏条目不被读取；
- 未识别章节不被误归类；
- 嵌套章节不会重复计数；
- `raw_text` 的长度限制、快照清洗和消息校验；
- 解析期间没有点击、聚焦或滚动操作；
- 旧版简历解析测试继续通过。

完成后执行扩展全量测试、类型检查、生产构建和被动读取安全扫描，并将构建产物同步到 Chrome 当前加载的 `extension/dist`。最后对本次代码差异进行 Review，只修复真实发现的问题。

## 非本轮范围

- 不精确拆分公司、职位、日期、学校、专业和学位；
- 不接入 LLM 或生成真实匹配评分；
- 不读取 BOSS 内部接口、Vue 状态、Webpack 状态或网络响应；
- 不新增账号、权限或服务器部署逻辑。
